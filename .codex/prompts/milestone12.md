Milestone 12 — Component Validation

Read .codex/instructions.md before making any changes.

Objective

Validate the Browser AI Agent's understanding of real application pages before allowing autonomous execution.

The goal is to verify that the agent correctly identifies page components and semantic relationships.

Scope

Using real-world job application websites, validate:

- page understanding
- field detection
- required field detection
- label association
- dropdown recognition
- checkbox recognition
- radio button recognition
- upload component recognition
- navigation button detection
- validation message detection

Generate a structured validation report describing:

- detected components
- missing components
- unsupported components
- confidence
- potential risks

Constraints

The browser may inspect the page but must not modify it.

No typing, clicking, uploading, or navigation.

Deliverables

- Component Validator
- Validation Report
- Component Coverage Metrics
- Unsupported Component Detection
